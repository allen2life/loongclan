# 龙族通用技术规范：通用数据同步协议 (SPEC_SYNC)

**版本**：v1.0.0  
**核心哲学**：本地优先（Local-First）与用户数据主权（Obsidian 范式）

---

## 1. 架构与同步模型

```
┌────────────────────────────────────────────────────────┐
│                        客户端（浏览器 / APP）          │
│                                                        │
│   localStorage / IndexedDB  ←→  同步引擎  ←→  Sync API │
│          （本地真相源）              ↑           ↑     │
│                                用户主动触发   仅中继存储│
└────────────────────────────────────────────────────────┘
```

1. **绝对真相源**：本地存储为最高优先级真相源。应用无网络时 100% 正常运行，所有游戏进度即时落盘本地。
2. **中继存储**：服务端只做快照（Snapshot）级存储与比对，不强行解析、修改或拆分具体的业务字段。
3. **多应用租户隔离**：通过 `appId` 字段天然隔离各游戏或应用数据。同一口令可在不同应用拥有各自独立的数据快照。

### 1.1 客户端 UI 展示与隐私保护铁律（口令保密，展示昵称）

所有接入 LoongClan 同步体系的客户端应用（包括单机小游戏、工具、官方门户等）必须严格遵循以下 UI 呈现铁律：
1. **口令保密原则**：三维口令是用户自持的数据恢复私钥与身份凭据，属于敏感保密信息，严禁在常规界面常驻暴露；
2. **界面统一显示昵称**：主界面顶栏、导航条、状态栏、排行榜名片等常驻区域，**一律显示用户昵称（Nickname）**，禁止直接展示明文三维口令；
3. **凭据查看默认脱敏**：在“账号与同步”或凭据备份管理面板中，口令默认必须采用类似手机号码的遮罩格式进行部分脱敏展示（如 `loong.***.***` 或 `poet.***.dragon`，使用 `LoongIdentity.mask(kouling)`），并提供眼睛切换图标（👁️）与一键安全复制功能；
4. **智能输入与防窥保护**：跨设备迁移或导入口令时，输入框应支持密码遮罩（`type="password"`）及一键粘贴自动分段识别，防止在公共场合或录屏中被旁窥。

## 2. API 接口定义

> **零明文口令交互与 UTF-8 字节流铁律**：  
> 1. 所有 API 交互**严禁传输口令原文**，客户端仅传输散列后的密文（`userHash` 作为公开身份，`syncToken` 作为私密鉴权凭证）。服务端绝不接收、绝不存储明文口令！  
> 2. 客户端计算 `userHash` 与 `syncToken` 时，**必须统一使用标准 UTF-8 字节流（即 `new TextEncoder().encode(input)`）**，以保证包含汉字、任意符号与 Emoji 的同一口令在任何设备、任何平台上算出的 Hash 严格绝对一致。

所有请求均采用 `application/json` 格式交互。

### 2.1 上传数据快照 (Upload Snapshot)

- **路径**：`POST /api/v1/sync/upload`
- **说明**：将客户端当前最新数据快照上传至云端。

#### 请求体 (Request Body)
```json
{
  "appId": "words",
  "userHash": "8a3f...64位公开身份标识...",
  "syncToken": "c72b...64位私密鉴权密文(口令派生)...",
  "nickname": "文脉探求者",
  "clientVersion": "1.0.0",
  "snapshotAt": "2026-09-09T09:00:00Z",
  "localVersion": 12,
  "force": false,
  "payload": {
    "stats": { "played": 20, "won": 18, "streak": 5 },
    "records": ["wm-001", "wm-002"],
    "preferences": { "sound": true }
  }
}
```

#### 字段说明
| 字段 | 类型 | 必选 | 说明 |
| :--- | :--- | :--- | :--- |
| `appId` | string | 是 | 应用标识符（如 `xiangqi`, `words`, `shizang` 等，1-32字符） |
| `userHash` | string | 是 | 64位十六进制公开身份标识 |
| `syncToken` | string | 是 | 64位十六进制私密鉴权密文（由前端本地从口令派生，绝不传输口令原文） |
| `nickname` | string | 否 | 用户昵称（1-30字符） |
| `clientVersion` | string | 否 | 客户端版本号 |
| `snapshotAt` | string | 是 | 快照产生的时间（ISO 8601） |
| `localVersion` | number | 是 | 本地乐观锁版本号（本地每次更新 +1） |
| `force` | boolean | 否 | 为 true 时强制以本地覆盖云端，忽略版本冲突 |
| `payload` | object/string | 是 | 用户数据的完整快照，服务端原样存储 |

#### 响应 (Response)

- **成功（200 OK）**：
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "serverVersion": 13,
    "savedAt": "2026-09-09T09:00:01Z",
    "conflict": false
  }
}
```

- **检测到版本冲突（409 Conflict）**：
  若云端版本已大于 `localVersion` 且未开启 `force` 时触发：
```json
{
  "code": 409,
  "err_code": "version_conflict",
  "message": "服务器版本更新，请先拉取最新快照进行合并",
  "data": {
    "conflict": true,
    "serverVersion": 18,
    "serverSnapshotAt": "2026-09-09T08:55:00Z"
  }
}
```

- **鉴权密文不匹配（401 Unauthorized）**：
```json
{
  "code": 401,
  "err_code": "token_mismatch",
  "message": "鉴权密文与已绑定的云端记录不一致"
}
```

### 2.2 下载数据快照 (Download Snapshot)

- **路径**：`POST /api/v1/sync/download`
- **说明**：从云端拉取已保存的最新数据快照。

#### 请求体 (Request Body)
```json
{
  "appId": "words",
  "userHash": "8a3f...64位公开标识...",
  "syncToken": "c72b...64位私密鉴权密文..."
}
```

#### 响应 (Response)

- **成功（200 OK）**：
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "appId": "words",
    "userHash": "8a3f...",
    "nickname": "文脉探求者",
    "serverVersion": 13,
    "snapshotAt": "2026-09-09T09:00:01Z",
    "payload": {
      "stats": { "played": 20, "won": 18, "streak": 5 },
      "records": ["wm-001", "wm-002"],
      "preferences": { "sound": true }
    }
  }
}
```

- **云端无快照（404 Not Found）**：
```json
{
  "code": 404,
  "err_code": "no_snapshot",
  "message": "云端暂无此口令的历史快照"
}
```

### 2.3 查询快照元数据 (Snapshot Metadata)

- **路径**：`POST /api/v1/sync/meta` 或 `GET /api/v1/sync/meta?appId=words&userHash=...`
- **说明**：轻量级检查云端最新版本号与最后更新时间，避免在版本无变化时全量下载 Payload。

#### 响应 (Response 200)
```json
{
  "code": 0,
  "data": {
    "serverVersion": 13,
    "snapshotAt": "2026-09-09T09:00:01Z",
    "size": 1420
  }
}
```

---

### 2.4 全量数据导出 (Export User Data)

- **路径**：`POST /api/v1/sync/export`
- **说明**：用户可一键导出该口令下所有绑定的数据（包括历史版本、多应用快照等），返回可下载的完整 JSON 备份。

---

### 2.5 永久删除云端数据 (Purge User Data)

- **路径**：`POST /api/v1/sync/purge`
- **说明**：响应用户数据主权，永久抹除该用户在云端的所有快照与排行记录。

#### 请求体
```json
{
  "appId": "words",
  "userHash": "8a3f...64位公开标识...",
  "syncToken": "c72b...64位私密鉴权密文...",
  "confirm": "DELETE_ALL_MY_DATA"
}
```

## 3. 客户端数据冲突与合并策略（CRDT 建议）

当多台设备并发修改发生冲突时，客户端推荐的合并策略如下：

| 数据类型 | 合并策略 | 示例字段 |
| :--- | :--- | :--- |
| **已通关关卡 / 解锁记录** | **取并集 (Union)** | `solvedIds: Array.from(new Set([...local, ...remote]))` |
| **成就列表** | **取并集 (Union，只增不减)** | `achievements: Array.from(new Set([...localAchs, ...remoteAchs]))` |
| **数值型统计（胜场、总分）**| **取较大值 (Max)** | `totalWon = Math.max(local.won, remote.won)` |
| **最高连胜纪录** | **取较大值 (Max)** | `maxStreak = Math.max(local.maxStreak, remote.maxStreak)` |
| **用户配置 / 昵称** | **取最新修改方 (LWW)** | 依据 `snapshotAt` 较新的一方覆盖 |

## 4. 前端同步 UI 隐私保护与交互铁律（所有 loongclan 应用强制遵循）

在数据同步的整个生命周期中，**三维口令是用户的唯一核心保密凭据（私钥/恢复密钥），绝对属于保密信息，一般不显示。口令原文 100% 留在前端客户端，绝对禁止向服务端传输口令原文**。所有归属于 `loongclan` 旗下的应用在设计与实现数据同步相关界面时，必须无条件遵循以下交互铁律：

### 4.1 常驻界面：统一显示“用户昵称”，严禁展示口令
- **应用顶栏、导航栏、个人资料摘要、排行榜个人条目等常驻 UI 区域，一律只展示用户的“昵称（Nickname）”**（如“小诗童”、“文脉探求者”、“弈林隐者”），辅以轻量同步状态图标（如 `Cloud` / `CloudCheck`）。
- **任何常驻 UI 组件严禁直接以明文显示用户的三维口令**，防止用户在日常使用、公开截屏、社交分享或直播演示时泄露私密凭据。

### 4.2 凭据回显：类似手机号码部分脱敏展示，支持主动显隐切换
- 在用户主动打开的“同步设置 / 账号管理”弹窗中：
  - **默认脱敏遮罩展示**：口令回显必须部分遮罩（类似手机号码 `138****1234` 隐藏敏感段），默认显示如 `loong.***.***` 或 `part1.***.part3`；
  - **显隐切换控件**：在脱敏口令旁必须提供眼睛图标按钮（👁️ / 🙈），仅在用户明确主动点击后才临时切换为完整明文；
  - **一键安全复制**：提供独立的快捷复制按钮，点击直接复制完整口令至剪贴板，并伴随安全反馈提示（如“口令已复制，请妥善保管”）。

### 4.3 三输入框交互铁律（Smart Input）
当用户在“使用已有口令”、“更换设备恢复存档”等场景需要手动输入口令时：
- **输入框必须为三个独立输入框（强制）**：
  - 界面呈现结构：`[ 输入框 1 ] . [ 输入框 2 ] . [ 输入框 3 ]`；
  - 严禁单框手动打点，彻底消除中英文句号混淆；每段输入限制 1~8 字符（支持汉字、字母、数字、特殊符号与表情符任意字符）；
- **智能跳格联动**：第 1 框满 8 字符或键入点号自动聚焦至第 2 框；第 2 框满 8 字符自动聚焦至第 3 框；
- **退格智能回退**：当前框为空时按退格键（Backspace），焦点自动退回前一框末尾；
- **智能一键粘贴分段**：剪贴板中的完整口令（如 `loong.888.abc`）在任一框粘贴时，组件自动按点号拆分成三部分分别填入三个输入框；
- **密码掩码与防窥保护**：
  - 三个输入框默认以密码模式（`type="password"`）遮蔽字符，配备统一切换明密文的眼睛按钮；
- **自动去除首尾空白（Trim）**：
  - 自动 trim 消除不可见空格，防止因误触空格导致哈希不一致。

### 4.4 生态全员遵循要求
- 本条规则属于 `loongclan` 统一底座的最高级非功能性强制红线（P0），适用于矩阵内全部产品（《棋阵风暴》、《诗藏》、《文脉》、《小诗童》等）及未来所有新上线产品。
